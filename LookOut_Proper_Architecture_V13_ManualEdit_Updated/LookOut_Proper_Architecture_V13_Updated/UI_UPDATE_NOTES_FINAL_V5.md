# AI Edit UI Update V5

- Removed the duplicate local Quick Actions rail; AI Edit now uses the global Home-equivalent workspace dock.
- The global dock remains only two controls: lightning (Quick Actions) and grid (Explore Features), centered vertically immediately beside the main sidebar.
- Kept the dock's existing Home behavior and actions.
- Removed any fixed editor/canvas work ratio for uploaded images.
- Uploaded images preserve their intrinsic aspect ratio with contain-style sizing.
- One image uses its own natural ratio; two images share the preview area while each preserves its own ratio.
- Prompt remains hidden before upload.
- After upload, prompt appears compact; clicking/focusing expands it horizontally from both sides.
- Prompt is constrained to the central preview workspace and does not overlap the feature panel.
- Feature panel remains vertically scrollable.
- Top Simple/Advanced controls are positioned above the workspace rather than overlapping the feature panel.
